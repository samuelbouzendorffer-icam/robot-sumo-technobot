# robot-sumo-technobot

Robot autonome de **sumo** conçu pour le concours **TechnoBot 2023**, dans le cadre de l'option Sciences de l'ingénieur.

## Le projet

- **Équipe** : 3 personnes. **Mon rôle** : chef de projet, avec conception, programmation et présentation.
- **Durée** : 3 semaines de préparation.
- **Résultat** : demi-finale du concours de sumo.
- **Présentation** : le projet a été présenté en anglais devant un jury (PowerPoint).
- **Outils** : C++, Arduino, Spyder, Autodesk Inventor (modélisation).

## Principe du sumo robotique

Deux robots autonomes s'affrontent sur un ring : le but est de pousser l'adversaire hors du cercle sans en sortir soi-même. Le robot doit donc, sans intervention humaine, détecter les bords du ring et repérer son adversaire, puis choisir son action.

## Contenu du dépôt

Ajoutez ici uniquement les fichiers que vous avez réellement :

- `src/` : programme Arduino / C++ du robot ;
- `cao/` : fichiers de modélisation Inventor ou captures d'écran ;
- `presentation/` : diaporama de la présentation au jury ;
- `docs/` : photos du robot, schéma de câblage.
